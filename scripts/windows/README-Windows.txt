MRX ScreenSaver for Windows
===========================

Requires: Windows 10/11 + WebView2 Runtime
  https://developer.microsoft.com/microsoft-edge/webview2/

INSTALL
-------
1. Unzip this folder.
2. Right-click MRXScreenSaver.scr → Install
   OR double-click Install.bat
3. In Screen Saver Settings, select "MRXScreenSaver" → Apply.

TEST WITHOUT INSTALLING
-----------------------
Double-click MRXScreenSaver.scr
(or run: MRXScreenSaver.scr /s)
Move the mouse or press a key to exit.

Download page:
https://github.com/Taibur-Rahaman/MRX-ScreenSaver/releases
