MRX ScreenSaver — Linux / Ubuntu
==================================

A Flipqlo-style flip clock screensaver for Linux desktops.

Requirements
------------
- WebKitGTK 4.1 (usually pre-installed on Ubuntu 22.04+)
- For XScreenSaver integration: sudo apt install xscreensaver

Quick install
-------------
1. Unzip MRXScreenSaver-Linux.zip
2. Open a terminal in the folder
3. Run: bash install.sh
4. Launch: mrx-screensaver

XScreenSaver (recommended on Ubuntu)
------------------------------------
After install.sh:
  bash configure-xscreensaver.sh

Then open XScreenSaver Settings → select "MRX Flip Clock" → Preview.

GNOME / KDE
-----------
Search for "MRX ScreenSaver" in your app launcher, or run:
  mrx-screensaver

Move mouse or press any key to exit.

Uninstall
---------
  bash uninstall.sh
